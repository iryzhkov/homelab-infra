## Unowned stacks (review should-fix, 2026-10-03)

Warnings alone exit 3, which `homelab-backup-run` posts to the feed as `warn` (`swarm snapshots incomplete on <host>`); any failure still exits 1 and posts `fail`. A stack that is pinned but not yet deployed, or pinned to the other node, is not reported.

A stack's `swarm-prepare.yml` can include it with `swarm_owner_stacks: [<stack>]`, delegated to the pinned node (usage in the file's header); the existing prepare files already write the owner file themselves, so none was changed.
